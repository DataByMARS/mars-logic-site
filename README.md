# MARS Maintenance Site

Minimal static maintenance page for www.mars-logic.com.

## Files

- `index.html`: main maintenance page
- `404.html`: displays the same maintenance page for missing routes
- `styles.css`: responsive styling
- `images/mars-logo.png`: MARS wordmark
- `images/favicon.png`: browser icon
- `CNAME`: GitHub Pages custom domain
- `.nojekyll`: disables Jekyll processing
